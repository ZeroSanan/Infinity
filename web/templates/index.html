Binance API Setup

1. Go to Binance → API Management
2. Create key with Spot trading enabled
3. Whitelist your IP address
4. Futures / Margin not needed
5. Each account runs independently

📓 How to set up Testnet

1. Go to testnet.binance.vision
2. Log in with your GitHub account
3. Click Generate HMAC_SHA256 Key
4. Copy the API Key and Secret Key
5. Paste them in the account form on the right
6. Check "Use Testnet (paper trading)" and click Save & Connect
7. Click Test — you should see a testnet balance (usually 1 BTC + 10,000 USDT, free)
8. Go to the Strategies tab
9. Click 📋 Copy to Testnet on any live strategy
10. Start the testnet engine and watch it trade with fake money

What is a DCA Model?

A DCA Model is a shared bull (long) + bear (short) ladder template.

Applying it to a coin card switches that coin to mode = "mixed" — an auto-switching engine that trades LONG in bullish regimes and SHORT in bearish regimes on Binance USD-M Futures, using leverage.
